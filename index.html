📝 學術被動語態 (Passive Voice) 快速指南

1. 核心公式與目的

be 動詞 + P.P. (過去分詞)

在工程與學術寫作中，用來客觀陳述事實，將焦點放在「動作的結果」而非「誰做的」。

The models were updated yesterday.

2. 進行式的被動

be 動詞 + being + P.P.

當主動句是進行式時，被動句必須加上 being 來維持「正在進行」的語感。

The results are being analyzed. (結果正在被分析)

3. 完成式的被動

have/has/had + been + P.P.

當主動句是完成式時，被動句必須加上 been 來維持「已經完成」的狀態。

A vulnerability has been discovered. (漏洞已經被發現)

4. 主詞提升 (高級學術寫法)

S + is expected to + V...

避免用 "People expect..."，改以事物為主詞，顯得更加專業且客觀。

The new policy is expected to improve stability.
